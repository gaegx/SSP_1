# Лабораторная №1 — SSR-список задач

Простое серверное приложение на **Node.js + Express + EJS**. Сервер отдаёт готовую HTML-разметку, изменения выполняются отправкой форм (без клиентского JavaScript).

## Возможности

- список задач со статусом: к выполнению / в работе / выполнена
- фильтр по статусу (форма `GET`)
- ожидаемая дата завершения
- создание, правка и удаление задач (формы `POST`)
- вложения файлов к задаче, скачивание и удаление файла

## Запуск

```bash
npm install
npm start
```

Откройте [http://localhost:3000](http://localhost:3000).

Данные хранятся в `data/tasks.json`, загруженные файлы — в `uploads/`.

## Проверка
